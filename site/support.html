How to report a problem

When contacting support, include the following information so the issue can be investigated quickly:

  • What happened — describe the problem clearly
  • Date and time (UTC)
  • Vehicle and device IMEI (if relevant)
  • Backend logs — output of pm2 logs <PROJECT_NAME> --lines 100
  • Screenshot (if possible)
🔐

Never include passwords, tokens or keys in support messages or screenshots.
